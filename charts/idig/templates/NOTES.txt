Wave {{ .Values.deployment.wave }} deployed. Track the IDIG cluster rollout (can take up to 20 minutes):

  kubectl get datapowerinteractgatewaycluster {{ .Values.idigCluster.name }} \
    -n {{ include "idig.namespace" . }} -o jsonpath='{.status.phase}{"\n"}'

Once phase is "Ready", list the Gateway API ingress endpoints:

  kubectl get gateway,httproute -n {{ include "idig.namespace" . }}

NOTE: On OpenShift the Ingress Operator owns the GatewayClass / Gateway
objects and exposes each HTTPRoute via an OCP Route automatically -- check
Routes as well if the above shows no external addresses:

  oc get routes -n {{ include "idig.namespace" . }}

Console UI admin credentials:
